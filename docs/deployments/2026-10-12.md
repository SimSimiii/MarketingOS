# Lambda rollout - 12-13 October 2026

## Changes

- Email launch uses Standard Step Functions (Plan, Craft per email, Finish).
- PostgreSQL holds admission, quota, immutable request/context, cursor, cancellation and usage.
- Replayed craft positions do not purchase the next email. Interrupted calls are not retried automatically.
- Recovery preserves accepted emails; a 15-minute reconciler repairs stranded jobs.
- Market, knowledge compilation and LinkedIn tools dispatch a dedicated asynchronous Lambda.
- Provider credentials are read from SSM at invocation time, cached for 60 seconds.
- `marketingos-egress-prod` provides private subnet NAT egress. One NAT gateway, recurring charges, no multi-AZ egress redundancy.
- Credit billing is refused for distributed jobs pending integration. The current production credit billing setting is disabled.

## Boundaries

Each campaign step and each background job has a 900-second Lambda ceiling. A slow step may degrade the result; background jobs are not split across invocations. LinkedIn campaigns finish within the planning invocation. Synchronous model-based image ingestion remains outside this rollout. Standalone LinkedIn search, criteria and message tools are dispatched to Lambda.

API keys are stored in `/marketingos/prod/anthropic-api-key` and `/marketingos/prod/openai-api-key` (eu-west-3); both were replaced and accepted on 13 October. Do not put credentials in Git or chat. API billing is separate from personal CLI subscriptions.

The periodic reconciler may keep Aurora awake and increase database running time. NAT and API usage incur ongoing charges.
