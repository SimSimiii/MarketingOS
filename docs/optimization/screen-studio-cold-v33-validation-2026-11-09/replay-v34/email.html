Keep the cursor editable after recording

Hi there,

When a product walkthrough is recorded in Screen Studio on macOS, the cursor can still be adjusted afterward—so each move can guide viewers through the feature you are showing.

Screen Studio is screen recording software for Mac. It captures precise mouse-movement data separately from the screen, synchronizes it with the video, and adds the cursor to the final result.

That means you can smooth cursor movement or change its size and style after recording, instead of starting the walkthrough again.

When it is ready, export the finished video at up to 4K and 60 fps on every plan.

Screen Studio supports macOS only, with macOS 13.1 or later recommended.
