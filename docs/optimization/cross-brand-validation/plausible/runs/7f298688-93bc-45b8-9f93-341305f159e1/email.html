Hi there,

Plausible Analytics lets you turn a completed trial signup into a conversion goal, then see which referrer sources and entry pages brought those conversions. That gives you more context than a topline signup total or rate.

First, check how signup completion appears on your site—not simply whether someone visited the signup page.

If completion reaches a dedicated confirmation page, you can create or review a pageview goal for that page. Plausible collects pageviews automatically, so this route needs no site code changes. If there is no distinct completion page, assess a custom event instead.

Once conversions are recorded, the dashboard can show the conversion count and rate, referrer sources, entry pages and pages where people converted.

The official guide explains both goal types so you can decide which one represents a completed trial signup correctly.
