Turn trial signup completion into a goal and see where those signups came from. Plausible Analytics is a privacy-friendly web analytics tool that shows website traffic and signup conversions in one dashboard.

If signup ends on a distinct confirmation page, set that page as a pageview goal with no code changes. If there is no distinct page, use a custom event goal, which requires a code snippet or script.

After the first conversion is recorded, the goal appears in the Goals section. Filter the dashboard by that goal to review conversion rate, referrer sources, entry pages and the pages where visitors converted.

Inspect the official goal-conversions guide to decide whether your signup should use a pageview goal or a custom event goal.
