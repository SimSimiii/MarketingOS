Route authentication email through Resend

Hi there,

You can now use Resend as the custom SMTP provider for authentication email. Resend is a transactional email platform for developers, with a documented setup path for Supabase Auth.

If you use Supabase, connect your Resend SMTP credentials under Authentication, Email, then SMTP Settings. This changes the sender behind signup confirmations, password resets, invites, magic links, and OTPs.

Supabase’s rate limit remains a separate setting. After configuring custom SMTP, raise its initial 30-message-per-hour limit under Authentication, then Rate Limits; upgrading the Supabase plan alone does not configure a new SMTP sender.

Resend Pro has no daily email limit. The Free plan remains capped at 100 emails per day.

The guide shows the credentials and Supabase configuration path needed to assess the integration.
