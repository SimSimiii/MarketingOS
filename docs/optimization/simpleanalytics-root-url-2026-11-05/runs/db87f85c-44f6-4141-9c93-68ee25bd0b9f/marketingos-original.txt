Hi there,

Simple Analytics publishes its browser-facing analytics scripts as open source on GitHub. Municipal web and privacy teams can inspect what runs in a visitor’s browser before deciding whether a formal evaluation is warranted.

Simple Analytics is privacy-focused website analytics software. It measures website activity without collecting personal data, using cookies or gathering information that could fingerprint a visitor, so its own analytics script does not depend on visitor consent.

The documentation links directly to the user-facing source code and explains configurable script behaviour, including which pages, metrics and parameters can be collected or ignored. That gives technical and privacy reviewers a concrete basis for assessment.

The linked page lets your team examine the code and configuration options before deciding whether Simple Analytics should advance to a formal evaluation alongside the municipality’s current analytics setup.

Inspect the user-facing scripts → https://docs.simpleanalytics.com/script
