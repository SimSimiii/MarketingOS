Measure pageviews without personal data

Hi there,

Municipal web teams can measure pageviews with Simple Analytics, privacy-focused website analytics software that does not collect personal data, use cookies or gather information that could fingerprint a visitor.

Its user-facing scripts are open source on GitHub. Your technical and privacy reviewers can inspect the browser-facing code and see how the analytics collection works before considering it for a municipal website.

The documentation links directly to the source code and explains the available script configuration. It gives your team a concrete first step for deciding whether Simple Analytics warrants a formal evaluation alongside the municipality’s current analytics setup.

Inspect the user-facing scripts → https://docs.simpleanalytics.com/script
