Make one intake form adapt to each request

Hi there,

If your team is rebuilding customer intake, start with one real request flow. Choose the request types, then decide which questions the person actioning each one needs answered.

Tally is an online form builder with conditional logic. You can configure one form to adapt its questions to the request type and the requester’s previous inputs.

That means billing, onboarding and technical requests can follow different paths inside the same form, with the question set designed by your team.

When a suitable destination is available in Zapier’s catalogue, Tally’s published Zapier integration can pass submissions into that downstream app.

Build the first flow and see whether the branching fits your intake process. Tally offers unlimited forms and submissions for free within its fair usage guidelines.
