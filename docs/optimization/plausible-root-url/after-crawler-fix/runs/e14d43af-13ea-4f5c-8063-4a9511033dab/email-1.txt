Hi there,

See what cookie-free web analytics would give your team before opening a formal review. Plausible Analytics is a web analytics tool with a live example dashboard you can inspect without creating an account.

For an Information Governance or DPIA assessment, the design is specific: Plausible documents that it uses no cookies and collects no personal data about visitors.

To calculate daily unique visitor numbers, it hashes the visitor’s IP address and User-Agent with a rotating salt. The identifier changes daily, and the raw IP address and User-Agent are never written to disk.

Visitor data is processed exclusively on EU servers owned and operated by European companies. The live dashboard lets you assess the reporting experience alongside that documented privacy model, then decide whether a formal evaluation is warranted.
