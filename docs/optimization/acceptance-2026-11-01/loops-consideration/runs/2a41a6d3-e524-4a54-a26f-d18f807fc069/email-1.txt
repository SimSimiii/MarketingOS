Route Supabase Auth email through Loops

Hi there,

Supabase’s built-in sender is a test-only, rate-limited path. Moving auth email off it still leaves a replacement route to implement.

Loops is an email sending platform for SaaS that can handle Supabase Auth email through the Send Email Hook. Supabase calls an Edge Function you deploy; that function verifies the request and sends the matching Loops transactional email.

Each configured auth action type needs its own Loops template. A verified Loops sending domain is also required before those messages can send.

The Supabase documentation lays out this architecture and its required components, so you can judge whether the hook, Edge Function, action-specific templates, and verified domain fit your Auth setup before implementing it.

Read the Supabase docs → https://loops.so/docs/integrations/supabase
