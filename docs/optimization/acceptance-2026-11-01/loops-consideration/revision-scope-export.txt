Route Supabase Auth email through Loops

Hi there,

Loops is an email sending platform for SaaS that can handle Supabase Auth email through Supabase’s Send Email Hook.

Supabase calls an Edge Function you deploy, which sends the corresponding Loops transactional email. Each configured auth action type needs its own Loops template, and messages require a verified Loops sending domain.

Loops’ Supabase integration guide lays out this architecture and its required components. Review it to decide whether the Send Email Hook, Edge Function, action-specific templates, and verified sending domain fit your Auth email setup before implementing the route.

Read Loops’ Supabase guide → https://loops.so/docs/integrations/supabase
