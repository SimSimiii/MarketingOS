Hi there,

Choose the Loops route based on the Supabase Auth email types you need to send.

Loops is an email sending platform that supports two routes for Supabase Auth email. SMTP covers confirm signup, magic link, invite, change email and reset password.

The Send Email Hook covers all hook action types, including security notifications. It requires a Supabase Edge Function and one Loops template for each Auth email type you configure.

Either route requires a verified Loops sending domain. Loops’ official Supabase integration guide compares both routes, their coverage and the required setup.

Read the Supabase docs → https://loops.so/docs/integrations/supabase
