Separate Auth sending from onboarding sync

Hi there,

Loops is an email sending platform for SaaS teams that supports two Supabase jobs: sending Auth email and bringing synced users into onboarding workflows.

These are independent integrations. Auth email uses Supabase’s Send Email Hook with an Edge Function and one Loops template for each configured auth email type. Sending through Loops also requires a verified Loops sending domain.

Onboarding uses a separate contact-sync integration. It adds Supabase users to a Loops audience, where their contact records can trigger onboarding workflows. The Send Email Hook does not perform this sync.

The Supabase integration guide published by Loops shows both paths and their requirements, so you can compare the architecture with your planned setup before creating an account or changing production infrastructure.

Read the Supabase integration docs → https://loops.so/docs/integrations/supabase
