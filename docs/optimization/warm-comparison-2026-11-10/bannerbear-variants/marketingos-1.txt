Turn two product inputs into two seasonal banners

Hi there,

Bannerbear’s Image API renders ecommerce banners from templates and supplied data. Begin with one seasonal image template and prepare two product-data inputs.

For the first banner, send an authenticated POST request to the Image API’s `/v5/images` endpoint with your API key and the first product’s `IMAGE_DATA`. For the second, keep the template choice fixed and replace the product data in the request body.

That gives you one bounded workflow: configure the design once, then use each request to supply the content for a different seasonal product-banner variant.

Open the documented REST API and OpenAPI specifications to structure those first two requests. The reference shows the implementation details behind each render: https://developers.bannerbear.com/v5/
