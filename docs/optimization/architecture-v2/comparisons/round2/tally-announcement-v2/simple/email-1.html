Build the form your workflow starts with

Hi there,

Tally is officially here: an online form builder that works like a document. Type questions directly on the page, then add blocks for contact details, payments, signatures, file uploads, ratings, and more—without writing code.

That makes it useful when a form is the front door to a bigger workflow. Build the questions in plain sight, then shape what gets collected before anything moves downstream.

When you want to connect it, webhooks are available free to all Tally users and can POST each submission as JSON to another app or URL. Unlimited forms and submissions are free too, within fair usage guidelines.

Start with one real intake. You can create the form without signing up, see how the builder feels, and decide whether it fits the workflow you’re putting together.
