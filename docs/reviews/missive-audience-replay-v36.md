# Rejeu du choix d’audience sur Missive

La préparation corrigée a écarté l’agence qui gère plusieurs boîtes client et retenu une équipe de support qui partage une boîte. Le rejeu a utilisé une copie de la base d’audit avec les mêmes documents, le même objectif et la même carte d’audiences. Le périmètre de cette vérification couvre le choix d’audience et la création du brief.

La recherche ciblée a trouvé une preuve officielle que les destinataires externes ne voient pas les échanges internes d’une conversation. Le dossier a conservé une question décisive pour l’agence sur la séparation de plusieurs boîtes et de leurs accès. La recommandation est restée `DISCOVERY_ONLY` pour l’agence. [Documentation Missive](https://missiveapp.com/docs/core-features/conversations/internal-chat)

Pour l’équipe de support, la preuve sur les échanges internes sert un usage concret dans une boîte partagée. Le système a autorisé un premier email sur cet usage avec `GO_NARROW`. La préparation a utilisé huit appels, dont deux pour vérifier la question produit. Elle a réutilisé la compilation et le scan concurrentiel.
