# Audience evidence integrity

Audience discovery and research now preserve the meaning of evidence across refreshes.

- Missing source URLs are first recovered literally from the discovery report. If a
  report describes searches but contains no usable URLs, one balanced search-enabled
  call locates fresh pages. It has no shared memory with discovery. The same bounded
  fetch and exact-quotation verification follow, including when recovery finds nothing.
- Research carries a fingerprint of the audience's organization, workflow, need,
  situation, trigger and membership criteria. Rewording substantive fields conservatively
  requires fresh research. Display names and rankings are not part of the fingerprint.
  Legacy research can recover this identity only from its exact, brand-scoped source map
  and matching definition. A changed geographic/language/objective/exclusion scope
  prevents reuse. Historical records remain available without being treated as current.
- A minor, explained objection permits exploration. Material or unassessed counterevidence
  routes otherwise researchable audiences to **Review counterevidence**. Only explicit
  unsupported requirements establish incompatibility. Impact labels are model judgments
  for human review, not measured conversion probabilities.
- Copied quotations do not create additional corroboration. When merging deep research,
  only buyer-voice sources count toward need evidence; vendor commentary does not become
  an independent buyer merely by appearing beside a real customer quote.
- Stored capability profiles are revalidated on read against the current knowledge ledger.
  A model paraphrase cannot license an unrelated quotation. Explicit aliases support the
  product's vocabulary; negative/planned-support wording is conservatively rejected.
  This lexical check is a guard, not a semantic proof. Rejected attachments stay inspectable.
- Audience provenance is checked against ledger quotations and their source. A testimonial
  can remain a customer observation on a vendor-hosted site. Product copy stays a vendor
  claim, and unsupported quotations become hypotheses. Evidence answering an objection
  cannot establish that a customer expressed that objection.

## Cost and data

No model call is needed for merging, ranking, provenance checks or profile revalidation.
URL recovery replaces the previous fast, closed-world recall with at most one balanced
web-search call when literal recovery fails. This conditional call costs more but can
actually find pages. It is outside the email campaign pipeline and its forecast. No live
model run is needed to test these paths: scripted providers and a fixed fetcher exercise
them offline. No schema migration or rewrite of historical SQLite payloads is required.

These changes improve evidence handling. They do not establish market size, purchase
intent or conversion performance, and do not implement the separate multi-angle or
company-first LinkedIn expansion.
