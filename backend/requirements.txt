# Lambda bundle for the platform API.
#
# `pyproject.toml` is the source of truth for a developer's environment; this
# file is what `sam build` installs into the function. It exists separately for
# two reasons: SAM's Python builder reads requirements.txt and nothing else,
# and the deployed function needs one dependency a laptop does not (psycopg)
# while having no use for the dev tooling.
#
# Versions are floors rather than pins, matching pyproject. If the built
# bundle ever approaches Lambda's 250 MB unzipped limit, the document-reading
# group at the bottom is the block to move into a Lambda Layer - it is the
# heaviest and the least often changed.
