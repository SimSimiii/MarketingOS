# Lambda bundle for the back-office API.
#
# Much smaller than the platform's. The console reads and writes rows; it never
# calls a model, never reads a PDF and never renders an email, so none of that
# dependency tree comes with it. The `app` package it imports is vendored into
# this directory by the buildspec, and only the parts it touches need to
# import - which is why `claude-agent-sdk` and the ingestion libraries are
# absent even though `app` contains modules that use them.
